# Meeting App

## Стек

TypeScript + Next.js (App Router) + TanStack Query + TailwindCSS + Preact Signals + rsp

## Запуск

```bash
pnpm install
pnpm run dev
```

Команда `dev` запускает Next.js и server.js параллельно через пакет `concurrently`.

В браузере открыть http://localhost:3000/chat.

## Архитектура

Проект разделен на серверные и клиентские компоненты.

`app/chat/page.tsx` - Серверный компонент. Делает prefetch списка встреч и передает данные клиенту через `HydrationBoundary`. Список виден при выключенном JS.

`MeetingsList.tsx` - Клиентский компонент. Подхватывает данные из гидрированного кеша TanStack Query, кнопка «Обновить» перезапрашивает без перезагрузки страницы.

`Chat.tsx` - Клиентский компонент. WebSocket-чат с автоматическим переподключением через `@opensumi/reconnecting-websocket`. Отправленные сообщения появляются в ленте сразу. При обрыве соединения пользователь видит статус «Нет связи», неотправленные сообщения помечаются и уходят автоматически после восстановления связи.

Граница server/client проходит там где нужен браузерный API: WebSocket, обработчики событий, реактивное состояние.

Для исключения лишних ре-рендеров при вводе текста использованы Preact Signals и open-source библиотека `rsp` - инпут и кнопка обновляются без ререндера компонента.

Claude chat использовался для обсуждения каждого шага при разработке.
Время выполнения: ~3 часа + 1 час рефакторинг и оптимизация.
